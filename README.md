# Richardson J — Portfolio

A static personal portfolio built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser. The site uses Google Fonts when an internet connection is available; system font fallbacks are included.

## Publish with GitHub Pages

1. Create a new GitHub repository named `richardson-j-portfolio` (or another available name).
2. Upload all files in this folder to the repository root and commit them to the `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. GitHub will show the public website URL in the Pages section after deployment finishes.

The free GitHub Pages address will look like `https://YOUR-GITHUB-USERNAME.github.io/richardson-j-portfolio/`. A custom domain is optional.

## Files

- `index.html` — page content
- `styles.css` — layout, colors, responsive styles, and effects
- `script.js`, `boot.js`, `bg.js`, `fx.js`, `cursor.js` — page interactions and animation
- `favicon.svg` — browser icon
- `.nojekyll` — tells GitHub Pages to serve the static project directly
